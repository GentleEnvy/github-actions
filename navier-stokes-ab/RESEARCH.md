# Исследовательская часть: можно ли убрать силу из конструкции OpenAI?

Это рабочие заметки, а не доказательство. Всё, что здесь утверждается как факт о Lean,
проверено в `NavierStokesAB/`. Остальное — анализ с указанием источников.

## 1. Где сила в (C)/(D)

В пакете `openai/NavierStokesAndEuler` скорость строится явно как каскад:
«carriers», «cycles», «activation», срезки, периодизация. Затем сила определяется
как невязка:

`f := ∂ₜv + (v·∇)v − νΔv + ∇p`.

Скорость на каждом времени до момента разрушения имеет компактный носитель по
пространству. Например, `AxisymmetricFields.lean`:
`HasCompactSupport (fun x => velocity H K (t, x))`. В `ActualPeriodizedSignedRealization.lean`
и `SpatialLocalization.lean` используются срезки с компактным носителем.

## 2. Качественное препятствие: аналитичность

Гладкие решения **без силы** (на торе, а на `ℝ³` с конечной энергией) при `t > 0`
вещественно-аналитичны по `x`. См. Foias–Temam (тор), Masuda, Kahane, Grujić–Kukavica.
Аналитическая функция с компактным носителем тождественно равна нулю. Отсюда:

* поле скорости OpenAI **ни при каком выборе параметров** не является решением без силы;
* сила не «малая поправка», которую можно убрать возмущением. Любая попытка получить
  (¬A)/(¬B) должна использовать аналитические, некомпактные профили на всех временах.
  Срезки, окна и склейка, на которых держится конструкция, для этого запрещены.

Для уравнений Эйлера (`ν = 0`) сглаживания нет, и компактный носитель разрешён.
Поэтому OpenAI смогли обойтись без силы именно там. Формально в Lean это отражено так:
`NavierStokesAB.not_existenceR3_zero` — (A) при `ν = 0` ложно.

## 3. Количественное препятствие (Palasek)

По сообщениям о дискуссии в блоге Тао (сентябрь 2026), С. Палашек указал следующее.
В режиме без силы вязкая диссипация должна перевешивать усиление, которое конструкция
получает от неустойчивостей на разделённых частотах. Сила в (C)/(D) как раз оплачивает
этот дефицит на каждом шаге каскада.

Соответствие масштабов: при самоподобном профиле `u ~ (T−t)^{β−1} U(x/(T−t)^β)`
отношение вязкого члена к нелинейному равно `ν (T−t)^{1−2β}`.
* `β > 1/2`: вязкость побеждает у момента разрушения (и оценка Лерэ
  `‖u(t)‖_∞ ≳ (T−t)^{−1/2}` такое разрушение запрещает). Эйлеровские сценарии этого типа
  не переносятся на `ν > 0` без силы.
* `β = 1/2`: точно самоподобное разрушение исключено (Нечас–Ружичка–Шверак, Цай).
* `β < 1/2`: рост быстрее критического. Это совместимо с оценками Лерэ и
  Эскауриасы–Серёгина–Шверака, но нужного механизма никто не знает.

## 4. Что говорит свежая литература (по поисковым аннотациям)

* arXiv:2609.10262 «Distribution of Singular Data Generated by Compact Forced Navier–Stokes
  Blowup»: силы, дающие разрушение, плотны в `H^s` тогда и только тогда, когда `s < 1/2`.
  Силу можно сделать малой в слабых нормах, но не в критических, и не убрать совсем.
* arXiv:2609.17642 (по названию): точное решение Навье–Стокса «GD1998» с закруткой между
  сжимающимися пористыми стенками, пересмотренное в переменных подобия конструкции OpenAI.
  Это поиск точных решений без силы с той же геометрией, пока с границей.
* Т. Тао, averaged Navier–Stokes (2016): любое доказательство (A)/(B) обязано использовать
  тонкую структуру нелинейности, а не только энергетическое тождество и гармонический анализ.

## 5. Что сделано здесь в сторону (A)/(B)

Всё проверено в Lean, аксиомы стандартные:

* (B) для малых аналитических данных: `SmallData.existencePeriodic_of_small`.
* (B) для любого аналитического поля, умноженного на малое `ε`:
  `SmallData.existencePeriodic_of_analytic`.
* (B) для любого аналитического поля при достаточно большой вязкости:
  `SmallData.existencePeriodic_of_large_viscosity`.
* (B) для ABC/Бельтрами-течений любой амплитуды: `existencePeriodic_abc`.
* (A) и (B) не зависят от `ν`: `clayA_iff_existenceR3_one`, `clayB_iff_existencePeriodic_one`.
* (A) ложно при `ν = 0`: `not_existenceR3_zero`.

## 6. Следующие реалистичные шаги

1. **Критическая малость (Лэй–Линь).** Заменить `Σ e^{σ|k|}|û_k| ≤ πν/4` на
   `Σ |k|^{−1}|û_k| < ν` и отказаться от аналитичности данных. Нужно: вес `e^{c√t|k|}`,
   растущий со временем (Фояш–Темам), и отдельная гладкость в `t = 0`.
   Это покрывает все гладкие данные, малые в критической норме.
2. **Большие двумерные данные.** Поля, не зависящие от `x₃` (2D-3C). Нужна глобальная
   регулярность 2D Навье–Стокса: сохранение энстрофии, продолжение локального решения.
   Это первое бесконечномерное семейство **больших** данных без специальной алгебры
   (в отличие от Бельтрами).
3. **Критерий продолжения.** Формально свести (B) для аналитических данных к априорной
   оценке нормы Винера с весом. Это не решает задачу, но точно указывает, что нужно доказать.

Честная оценка: ни один из этих шагов не приближает решение (A)/(B) по существу.
Главная трудность — отсутствие контролируемой коэрцитивной величины выше уровня энергии.
Она не преодолевается ни формализацией, ни перебором частных случаев.
