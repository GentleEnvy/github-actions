# Навье–Стокс: варианты (A) и (B) рядом с результатом OpenAI для (C)/(D)

> **Статус:** все файлы компилируются без ошибок. `SmallData/` проверен против настоящих
> определений `NavierStokes.ComparatorDefinitions` из пакета OpenAI; остальные файлы проверены
> против копии тех же определений Formal Conjectures. Полная сборка с теоремами OpenAI
> (Mathlib + их ~2700 файлов) из исходников ещё идёт: кэш Mathlib в этом окружении недоступен.

## Коротко

Задача Клэя о Навье–Стоксе (Fefferman) требует доказать **одно** из четырёх утверждений:

| | утверждение | сила `f` | статус (сентябрь 2026) |
|---|---|---|---|
| (A) | глобальная гладкость на `ℝ³` | `f ≡ 0` | **открыто** |
| (B) | глобальная гладкость на `ℝ³/ℤ³` | `f ≡ 0` | **открыто** |
| (C) | разрушение на `ℝ³` | допустимая `f` | доказано OpenAI (Lean) |
| (D) | разрушение на `ℝ³/ℤ³` | допустимая `f` | доказано OpenAI (Lean) |

(C) и (D) **не являются отрицаниями** (A) и (B): в (A)/(B) сила равна нулю, а в (C)/(D)
разрушение достигается с помощью гладкой внешней силы. Поэтому результат OpenAI
не доказывает и не опровергает (A)/(B). В
[Formal Conjectures](https://github.com/google-deepmind/formal-conjectures/blob/main/FormalConjectures/Millennium/NavierStokes.lean)
(A) и (B) по-прежнему помечены `research open`.

**Доказательства (A) или (B) здесь нет.** Это открытая проблема тысячелетия, и любая
«проверенная в Lean» версия была бы либо с `sorry`, либо с подменённой формулировкой.
Вместо этого здесь формально проверено всё, что про (A)/(B) действительно доказуемо
сейчас, с опорой на теоремы OpenAI как на чёрный ящик.

## Что доказано в Lean

Определения не переписаны: используются ровно те же `NavierStokes.Comparator.*`
(копия Formal Conjectures), по которым проверяется работа OpenAI.
Пакет [`openai/NavierStokesAndEuler`](https://github.com/openai/NavierStokesAndEuler)
подключён как зависимость Lake, и их теоремы используются напрямую.

### 1. Точное место (A)/(B) относительно (C)/(D) (`Relations.lean`)

* `existenceR3_iff_not_unforcedBreakdownR3`: (A) при вязкости `ν` ⇔ нет разрушения **без силы**.
* `breakdownR3_iff_not_forcedExistenceR3`: (C) при `ν` ⇔ неверно «существование **с силой**».
* `existenceR3_of_forcedExistenceR3`, `clayC_of_unforcedBreakdownR3`: импликации идут
  только в одну сторону (нулевая сила допустима: `forceConditionDecay_zero`).
* `not_forcedExistenceR3`, `not_forcedExistencePeriodic`: **следствие теорем OpenAI**.
  Если разрешить силу, глобальное существование ложно при всех `ν > 0`.
* `clayA_iff`, `clayB_iff`: (A) ⇔ ∀ν>0 нет разрушения без силы. Этот вопрос открыт.
* Аналоги для тора: `…Periodic`.

### 2. Уравнения Эйлера: (A) ложно при `ν = 0` (`Euler.lean`)

OpenAI также доказали разрушение для **уравнений Эйлера без силы** (`Euler.euler_breakdown_R3`).
При `ν = 0`, `f = 0` класс решений Клэя совпадает с их классом решений Эйлера
(`euler_iff_navierStokes_zero`). Отсюда:

* `not_existenceR3_zero : ¬ ExistenceR3 0`: утверждение (A) при нулевой вязкости **ложно**.

Итоговая картина для `ℝ³`:

| вязкость | сила | глобальное существование |
|---|---|---|
| `ν = 0` | `f = 0` | ложно (Эйлер, OpenAI) |
| `ν > 0` | допустимая `f` | ложно ((C), OpenAI) |
| `ν > 0` | `f = 0` | **открыто = (A)** |

### 3. (A) и (B) не зависят от вязкости (`Scaling.lean`)

Если `(v, p)` решает уравнения без силы с вязкостью `ν` и данными `u₀`, то
`w(x,t) = a·v(x, a·t)`, `q(x,t) = a²·p(x, a·t)` решает их с вязкостью `a·ν` и данными `a·u₀`.
Масштабирование сохраняет гладкость, бездивергентность, ограниченность энергии и периодичность.

* `existenceR3_iff`, `existencePeriodic_iff`: (A) при одной `ν > 0` ⇔ (A) при любой `ν' > 0`.
* `clayA_iff_existenceR3_one`, `clayB_iff_existencePeriodic_one`: (A) и (B) сводятся к `ν = 1`.

### 4. Частные случаи, где (A)/(B) выполняются (`Beltrami.lean`, `ABC.lean`, `SpecialCases.lean`)

* `IsBeltrami.solution` / `IsBeltrami.periodicSolution`: если `U` гладкое, бездивергентное,
  `ΔU = −μU` и `(U·∇)U = ∇(|U|²/2)`, то `v = e^{−νμt}U`, `p = −e^{−2νμt}|U|²/2` является
  глобальным гладким решением (в любой размерности, при любой вязкости).
* `existencePeriodic_abc`: **(B) верно для всех ABC-течений** (Арнольд–Бельтрами–Чилдресс)
  `U = (A sin kz + C cos ky, B sin kx + A cos kz, C sin ky + B cos kx)`, `k = 2πm`, `m ∈ ℤ`.
* `existencePeriodic_const`, `existenceR3_zero_datum`, `existencePeriodic_zero_datum`:
  постоянные и нулевые данные.

Это не приближение к (A)/(B): это проверка, что формальные классы решений непусты,
и явное семейство данных, для которых вопрос (B) закрыт.

### 5. (B) верно для малых аналитических данных (`SmallData/`, ~2900 строк)

Главный содержательный результат. Это **глобальное существование и гладкость без силы**
в точной формулировке Клэя/Formal Conjectures (`NavierStokesExistenceAndSmoothnessPeriodic`),
но только для малых данных.

* `SmallData.existencePeriodic_of_small`: пусть
  `u₀(x) = Re Σ_{k∈ℤ³} c_k e^{2πi k·x}`, где `k·c_k = 0`, `c_{−k} = conj(c_k)` и
  `Σ_k e^{σ|k|}|c_k| ≤ πν/4` для некоторого `σ > 0`. Тогда `u₀` удовлетворяет
  `InitialVelocityConditionPeriodic`, и существуют `v, p` с
  `NavierStokesExistenceAndSmoothnessPeriodic ν u₀ 0 v p`.
* `SmallData.existencePeriodic_of_analytic`: **любое** аналитическое бездивергентное
  периодическое поле, умноженное на достаточно малое `ε`, даёт глобальное гладкое решение.
* Аксиомы: `#print axioms` показывает только `propext`, `Classical.choice`, `Quot.sound`.

Схема доказательства (тип Фудзиты–Като / Лэя–Линя, в алгебре Винера с аналитическим весом):

| файл | содержание |
|---|---|
| `Lattice` | `ℤ³`, `|k|`, суммируемость `|k|^m e^{−c|k|}` |
| `Conv` | свёртки в `ℓ¹(ℤ³)` как ограниченные билинейные отображения |
| `Duhamel` | тепловая полугруппа `e^{−νλ_k t}` и оператор Дюамеля на `C_b([0,∞))` |
| `Symbols` | проектор Лере `P_k`, символ нелинейности `−2πi P_k(k·x) y`, `λ_k = 4π²|k|²` |
| `FixedPoint` | отображение `Φ` и сжатие в шаре радиуса `πν/2`: ключевая оценка `∫₀^t e^{−νλ_k(t−s)}·2π|k| ds ≤ 1/(2πν)` и `e^{σ|k|} ≤ e^{σ|j|}e^{σ|k−j|}` |
| `Weighted`, `Regularity` | гладкость `C^∞` по времени на `[0,∞)` со значениями в `ℓ¹` с меньшим весом (индукция с потерей веса) |
| `Symmetry` | бездивергентность; вещественность через единственность неподвижной точки и сопряжение |
| `Fourier` | ряды Фурье с быстро убывающими коэффициентами: гладкость, почленное дифференцирование, лапласиан |
| `Fields`, `Cauchy`, `RealFields` | давление `p̂_n = −Σ_j (n·û_j)(n·û_{n−j})/|n|²`, конвективный член как произведение Коши, вещественные части |
| `Setup`, `Final` | поля `v`, `p`; уравнение проверяется по модам, затем собираются все поля структуры Клэя |

Почему это не (B): малость `Σ e^{σ|k|}|c_k| ≤ πν/4` существенна. Для больших данных
контракция не работает, и именно этот случай составляет открытую проблему.
